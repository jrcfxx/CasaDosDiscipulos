## Sobre

A **Casa dos Discípulos** centraliza formação, células e engajamento — com a identidade do portal: **Montserrat**, teal `#02869b` e dourado `#f4b002`.

| Diferencial | Descrição |
|-------------|-----------|
| Tudo em um lugar | Cursos, lições, formulários, eventos e escala |
| Formação gamificada | Módulos, quizzes e ranking |
| Secretaria digital | Formulários e relatórios por célula |
| WhatsApp | Escala e lembretes de módulos |
| Acessibilidade | WCAG 2.1 · teclado · leitores de tela |
| Segurança | JWT · bcrypt · Helmet · rate limit |

---

## Módulos

| Módulo | Público | Função |
|--------|---------|--------|
| Escola de Discípulos | Membros e líderes | Estudo, quiz, ranking |
| Secretaria das Células | Líderes e admin | Lições e formulários |
| Eventos | Todos | Carrossel |
| Fala Aí, Discípulo | Autenticados | Devocional |
| Escala | Líderes e admin | Ministérios |
| Gestão | Admin | Usuários e células |

## Stack

| Frontend | Backend | Produção |
|----------|---------|----------|
| React 18 · TypeScript | Node · Express 5 | Docker · Nginx |
| Router 6 · Axios | Knex · MySQL 8 | Let's Encrypt |
| Tokens · Montserrat | JWT · Joi · Helmet | Evolution API |

## Instalação rápida

```bash
git clone https://github.com/jrcfxx/CasaDosDiscipulos.git
cd CasaDosDiscipulos
```

```bash
# Backend
cd Codigo/backend && npm install && cp .env.example .env
npm run migrate && npm run seed && npm run dev

# Frontend (outro terminal)
cd Codigo/frontend && npm install && npm start
```
