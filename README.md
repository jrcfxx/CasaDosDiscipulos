## Sobre

Centraliza formação, gestão de células e engajamento da comunidade — com a identidade do portal: **Montserrat**, teal `#02869b` e dourado `#f4b002`.

| | |
|---|---|
| **Formação** | Módulos, quizzes e ranking |
| **Células** | Lições, formulários e relatórios |

---

## Início rápido

```bash
git clone https://github.com/jrcfxx/CasaDosDiscipulos.git
cd CasaDosDiscipulos/Codigo/backend
npm install && cp .env.example .env
npm run migrate && npm run seed && npm run dev
```

```bash
cd Codigo/frontend
npm install && npm start
```
